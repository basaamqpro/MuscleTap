# muscle-map-workout
An interactive fitness web app that allows users to tap muscle groups on a body diagram, filter workouts by equipment type, and watch targeted exercise videos through YouTube embeds.

## Overview

This project is a mobile-first front-end app built with **HTML**, **CSS**, **JavaScript**, and **SVG overlays**. Users can switch between the front and back body view, select a muscle group, choose an equipment category, and browse matching workout videos.

The goal of the project is to create a more visual and intuitive way to discover exercises based on body area rather than only text menus.

## Features

- Interactive clickable body map using SVG polygon overlays
- Front and back body view switching
- Muscle-group-based exercise selection
- Dynamic filtering by workout type / equipment
- Embedded YouTube video playback
- Dynamically generated video list with thumbnails
- Mobile-first layout

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- SVG
- YouTube embeds

## How It Works

1. The user selects a body side (front or back).
2. The user taps a muscle area on the diagram.
3. The app generates matching categories and workout videos.
4. The user can filter by workout type such as:
   - body weight
   - gym
   - dumbbell
   - bands
5. The user taps a video card to open and play the embedded YouTube workout.

## Why I Built This

I wanted to build a project that felt more like a real interactive product than a standard beginner app. Instead of using a basic list layout, I used a visual body map so users can discover workouts in a more natural way.

This project helped me practice:
